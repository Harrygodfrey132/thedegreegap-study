**Default rule: aim for 1-2 stat references per page maximum.** Three or more reads as marketing puffery and dilutes each one.

## Where NOT to use them

- **Hero H1** — these carry pain or aspiration, not awards. An H1 announcing an award reads as self-congratulation, not as something a parent needs.
- **Intro paragraphs (intro_1, intro_2 on location pages)** — these establish local context. Awards belong in trust strips, not the opening setup.
- **Reviews** — never paraphrase a stat into a review or near a review. They are different trust types.
- **FAQs** — answer the question. Don't pivot to bragging.
- **Pain-led copy** — when copy is doing pain-recognition work, an award undercuts it. Keep them separate.

## Natural integration rules

1. **Weave, don't bolt on.** "Our tutors clear a founder-led interview process designed to filter to roughly 3% of applicants" reads natural. "Did you know only 3% of tutors get accepted?" reads salesy. The first is descriptive; the second is sales.

2. **One stat per section maximum.** Don't stack two awards in one sentence. Don't list three credentials in a row.

3. **Skip stats entirely on small, scoped sections.** Eyebrows, CTA strips, one-line captions — these don't need credentials. Let them breathe.

4. **Match the stat to the section's purpose.** Schools intro → "Working directly with 15+ UK secondary schools". Tutor strip → "3% acceptance rate". Founder bio → LSE + Forbes/Independent. Don't put webinar attendance numbers on a location page.

5. **British English and house-style.** "five-star reviews", "co-founded", "5,000 hours" (numerals fine for numbers ≥1,000).

6. **No exclamation marks. No "Did you know" openers. No award stickers visualised in prose.**

## When the numbers change

This file is the source of truth. If a number ticks up (more reviews, more webinar attendees), update the number here. New pages pick it up automatically. Do not retrofit every existing page when a stat changes by a small amount.
