What's wired up

  • Click target: /referred-by-school-guide/ (opens in a new tab on partner sites). Swap for a per-partner URL when each placement goes live.
  • Messages cycle every 4 seconds for a 12-second loop. Respects the visitor's reduced-motion preference.
  • Message 1 leads with what we actually do, so partners and parents know the brand at a glance.
  • Message 3 shows the real Google G icon next to the review count, so the trust signal is verifiable at a glance.
  • Cream background, burgundy CTA, Poppins font — matches the site brand.
  • On mobile (under 600px) only the tutoring message is shown, no rotation, so the brand promise stays legible at a phone size.
