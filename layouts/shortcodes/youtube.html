{{- /* Lazy YouTube embed with VideoObject schema. Renders a thumbnail facade instead of an iframe. YouTube's player JS is only fetched when the parent actually clicks play, which keeps the post fast and stops YouTube setting cookies on people who never watch. Same approach as layouts/webinars/single.html, factored out so posts can use it. Emits VideoObject JSON-LD so the post is eligible for video rich results. uploadDate and duration are required by Google for that, so this errors rather than guessing: a wrong uploadDate is worse than no schema at all. Params: id (required) YouTube video ID, not the full URL title (required) video title, used for schema name and the aria-label description (required) one or two sentences, used for schema description uploadDate (required) YYYY-MM-DD, must match the real upload date duration (required) ISO 8601, e.g. PT40M1S thumbnail (optional) defaults to the video's maxres still on i.ytimg.com Usage: {{< youtube id="8VuxLCxcGkU" title="GCSE Results Day 2026 Tips & Advice" description="What the grades mean and what to do next." uploadDate="2026-08-17" duration="PT40M1S" >}} */ -}} {{- $id := .Get "id" -}} {{- $title := .Get "title" -}} {{- $desc := .Get "description" -}} {{- $uploaded := .Get "uploadDate" -}} {{- $duration := .Get "duration" -}} {{- with $id -}}{{- else -}}{{- errorf "youtube shortcode in %s: missing required param 'id'" $.Page.File.Path -}}{{- end -}} {{- with $title -}}{{- else -}}{{- errorf "youtube shortcode in %s: missing required param 'title'" $.Page.File.Path -}}{{- end -}} {{- with $desc -}}{{- else -}}{{- errorf "youtube shortcode in %s: missing required param 'description'" $.Page.File.Path -}}{{- end -}} {{- with $uploaded -}}{{- else -}}{{- errorf "youtube shortcode in %s: missing required param 'uploadDate'" $.Page.File.Path -}}{{- end -}} {{- with $duration -}}{{- else -}}{{- errorf "youtube shortcode in %s: missing required param 'duration'" $.Page.File.Path -}}{{- end -}} {{- $thumb := .Get "thumbnail" | default (printf "https://i.ytimg.com/vi/%s/maxresdefault.jpg" $id) -}}
